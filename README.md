# Terminologist

Сервис работы со справочными данными: управление версиями, получение элементов
и проверка их корректности.

## Основные возможности

Сервис предоставляет:

* управление справочниками;
* управление версиями справочников;
* управление элементами справочников;
* определение актуальной версии справочника;
* получение списка справочников;
* получение элементов конкретной или актуальной версии;
* проверку наличия элемента в версии справочника;
* административный интерфейс Django для управления данными;
* REST API с автоматически генерируемой документацией.

## Структура данных

Основные сущности системы:

### Справочник

Содержит:

* код;
* наименование;
* описание.

### Версия справочника

Связана со справочником и содержит:

* версию;
* дату начала действия.

### Элемент справочника

Связан с конкретной версией и содержит:

* код элемента;
* значение элемента.

Связь сущностей:

```text
Справочник
    │
    └── Версии
          │
          └── Элементы
```

## Стек

* Python 3.14
* Django 6.1
* Django REST Framework
* SQLite

## Требования

Перед началом работы необходимо установить:

* [uv](https://docs.astral.sh/uv/)

## Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/vladkachal/terminologist.git
cd terminologist
```

### 2. Установка зависимостей

Если зависимости проекта управляются через `uv`:

```bash
uv sync
```

После этого активировать виртуальное окружение:

```bash
source .venv/bin/activate
```

Для Windows:

```powershell
.venv\Scripts\activate
```

### 3. Настройка переменных окружения

Создать файл `.env` на основе `.env.template`:

```bash
cp .env.template .env
```

Отредактировать значения:

```env
SECRET_KEY=
DEBUG=
ALLOWED_HOSTS=localhost,127.0.0.1
```

### 4. Применение миграций

```bash
python src/manage.py migrate
```

### 5. Создание суперпользователя

Для доступа к административной панели:

```bash
python src/manage.py createsuperuser
```

Следуйте инструкциям Django в консоли.

### 6. Загрузка начальных данных

Для заполнения базы тестовыми/начальными данными:

```bash
python src/manage.py loaddata src/apps/terminology/fixtures/initial_data.json
```

Этот шаг является необязательным.

## Запуск

Запустить development-сервер Django:

```bash
python src/manage.py runserver
```

После запуска приложение будет доступно по следующим адресам:

- Документация API http://127.0.0.1:8000/api/docs/
- Административная панель http://127.0.0.1:8000/admin/ . Для входа используются учётные
данные суперпользователя, созданного на предыдущем шаге.

## Тестирование

Для запуска тестов приложения:

```bash
python src/manage.py test apps.terminology.tests
```
